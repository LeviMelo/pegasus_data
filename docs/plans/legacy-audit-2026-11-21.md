# Audit: case-specific logic in src/pegasus_data (read-only)

Scope: all of src/pegasus_data except tests, curation YAML, decode/_native and decode/lha (binary format constants).
src/pegasus_data/studies/ was skipped: it is study code (modelled_race, population_account, population_tensor).
Method: grep for quoted system/column/code literals, `==`/`startswith` on names, module-level constant tables, numeric literals in conditions, year literals; then read the surrounding code.
General finding: the core is largely clean. Literal system and column names in logic are rare. The debt is mostly (a) hand-written name tables that duplicate each other, (b) thresholds with no stated measurement, (c) a CNES-specific resource layer, (d) the same mechanism written several times (month parsing, year plausibility, extension-to-role, hierarchical codelist).
Line numbers are from the tree as read (2026-11-21).
